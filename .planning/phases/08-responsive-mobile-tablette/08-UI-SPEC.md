# Phase 8 — UI Design Contract: Responsive Mobile/Tablette

> Visual and interaction contract for Phase 8. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>

## Breakpoints

| Token | Valeur | Usage |
|-------|--------|-------|
| mobile | `max-width: 768px` | Hamburger menu actif, drawer pleine largeur, galerie 1 col |
| tablette | `max-width: 1023px` | Galerie 2 col (déjà en place), layout détail empilé |
| desktop | `min-width: 1024px` | Nav horizontale, galerie 3 col, drawer latéral, layout détail 2 col |

**Pattern obligatoire :** Les breakpoints s'expriment UNIQUEMENT via `<style>` inline avec `@media` — PAS de classes Tailwind `md:` ou `lg:`. Ce pattern est établi par MasonryGrid.tsx et artworks/[id]/page.tsx et doit être suivi rigoureusement dans tous les composants modifiés de cette phase.

**Exceptions Phase 8 :**
- Touch target minimum : **44×44px** sur tous les éléments interactifs (bouton hamburger, croix fermeture, liens nav panneau). Source : 08-CONTEXT.md D-02.

- Safe area iPhone : `padding-bottom: env(safe-area-inset-bottom, 16px)` sur le panneau hamburger.

## Typography

Héritée de Phase 3 (D-02). Aucun nouveau style typographique introduit en Phase 8. Ce qui change : les tailles doivent respecter le minimum **14px sur mobile** (les liens nav desktop à 11px sont masqués sur mobile, remplacés par les liens panneau hamburger à 14px).

| Role | Font | Size | Weight | Line Height | Usage |
|------|------|------|--------|-------------|-------|
| Display / Titre œuvre | Oswald | 28px (desktop) / 22px (mobile) | 700 | 1.1 | Titre œuvre page détail — décision Phase 3 D-16 |
| Heading / Logo nav | Oswald | 18px | 700 | 1.0 | Logo "Galerie POF" dans SiteNav — inchangé |
| Body | Cormorant Garamond italic | 16px | 400 | 1.55 | Descriptions œuvres — inchangé |
| Label / Nav desktop | Space Mono | 11px | 400 | 1.0 | Liens nav desktop — masqués sur mobile (≤768px) |
| Label / Nav mobile | Space Mono | 14px | 400 | 1.0 | Liens panneau hamburger — touch target 48px hauteur |
| Meta | Space Mono | 11px | 400 | 1.4 | Labels méta, badges, filtres — inchangé |

**Règle mobile :** Aucun texte interactif en dessous de 14px sur mobile. Le minimum 11px est réservé aux labels non-interactifs (méta, badges).

## Composants à créer ou modifier

### Nouveau : `HamburgerMenu.tsx` (Client Component)

Seul nouveau composant de la phase.

| Propriété | Valeur |
|-----------|--------|
| Type | Client Component (`'use client'`) |
| Fichier | `src/components/layout/HamburgerMenu.tsx` |
| State | `useState<boolean>(false)` — panneau ouvert/fermé |
| Props | `isLoggedIn: boolean`, `displayName?: string` |

**Anatomie du panneau :**

| Élément | Spec |
|---------|------|
| Bouton hamburger ≡ | 44×44px, fond transparent, 3 lignes `20×1.5px` couleur `--color-ink`, `border: none` |
| Overlay | `position: fixed; inset: 0; z-index: 50; background: rgba(26,26,26,0.5)` — `onClick` ferme |
| Panneau | `position: fixed; top:0; right:0; bottom:0; width: 280px; z-index: 51; background: --color-surface` |
| Croix fermeture | `44×44px`, alignée à droite dans le panneau, `margin-right: 16px`, `font-size: 22px` |
| Lien "Galerie" | `height: 48px; padding: 0 24px; Space Mono 14px uppercase letter-spacing: 0.08em; color: --color-ink` |
| Lien "À propos" | Identique à "Galerie" |
| Lien "Mon profil" (connecté) | `height: 48px; padding: 0 24px` + carré initiale 28×28px `border-radius: 0` |
| Lien "S'identifier" (non connecté) | `height: 48px; padding: 0 24px; color: --color-ink-muted` |
| Safe area bottom | `padding-bottom: env(safe-area-inset-bottom, 16px)` sur le panneau |

**Animation :** `animation: slideInFromRight 0.22s ease-out` — `@keyframes` dans une balise `<style>` locale (`translateX(100%) → translateX(0)`). Pas de bibliothèque de transition.

**Comportements obligatoires :**
1. `useEffect` : `document.body.style.overflow = 'hidden'` quand `isOpen === true` ; nettoyage à la fermeture et au démontage.
2. `useEffect` : écouter `keydown` pour `Escape` → fermer le panneau (accessibilité clavier).
3. `aria-label="Ouvrir le menu"` + `aria-expanded={isOpen}` sur le bouton hamburger.
4. `role="dialog"` + `aria-label="Menu de navigation"` sur le panneau.

### Modifié : `SiteNav.tsx` (Server Component async — inchangé dans sa nature)

| Changement | Spec |
|------------|------|
| Importer `HamburgerMenu` | Composant fils Client — SiteNav reste async Server Component |
| Wrapping desktop links | `<div className="sitenav-desktop-links">` |
| Wrapping hamburger | `<div className="sitenav-hamburger">` |
| Balise `<style>` ajoutée | `.sitenav-desktop-links { display: flex; } .sitenav-hamburger { display: none; } @media (max-width: 768px) { .sitenav-desktop-links { display: none; } .sitenav-hamburger { display: flex; } }` |
| z-index SiteNav | Reste à `z-index: 10` — overlay hamburger à 50, panneau à 51 (au-dessus de la nav) |
| Hauteur SiteNav | Conservée à 56px sur mobile |

**INTERDIT :** Ajouter `'use client'` à `SiteNav.tsx`. Cela briserait `await getVisitorSession()`.

### Modifié : `ArtworksClient.tsx` (admin drawer)

| Changement | Spec |
|------------|------|
| Classe CSS | Ajouter `className="admin-drawer-panel"` au `<div>` du drawer |
| Règle CSS `@media` | `@media (max-width: 767px) { .admin-drawer-panel { width: 100% !important; min-width: 0 !important; } }` |
| Grid padding | `@media (max-width: 767px) { .admin-grid-padding { padding-right: 0 !important; } }` |
| DRAWER_MIN | Constante JS inchangée — le CSS `!important` override le style inline sur mobile |

### Modifié : `FilterBar.tsx` (filtres galerie)

| Changement | Spec |
|------------|------|
| Container mobile | `overflow-x: auto; flexWrap: 'nowrap'` sous `@media (max-width: 768px)` |
| Comportement actuel | `flexWrap: 'wrap'` — chips passent à la ligne, non scrollable |
| Comportement cible | Barre scrollable horizontalement sur mobile, pills sans border-radius (D-03) |
| Scrollbar | Masquée : `-webkit-scrollbar: none; scrollbar-width: none` (cosmétique uniquement) |

### Vérifier : `artworks/[id]/page.tsx` (info panel sticky)

| Point de vérification | Spec |
|----------------------|------|
| `position: sticky; maxHeight: 100vh` | Ces règles doivent être actives uniquement en mode 2-col (≥1024px) |
| Correction si nécessaire | `@media (max-width: 1023px) { .detail-info-panel { position: static; max-height: none; } }` dans la balise `<style>` existante |
| `scroll-padding-bottom` | Ajouter sur le conteneur scrollable pour garder `OfferForm` visible quand clavier virtuel ouvert |

## Touch Targets — Audit Obligatoire

Tous les éléments interactifs doivent respecter 44×44px minimum (WCAG 2.5.5).

| Élément | Taille actuelle | Cible Phase 8 |
|---------|----------------|---------------|
| Bouton hamburger | NOUVEAU | 44×44px — `width: 44px; height: 44px` |
| Croix fermeture panneau | NOUVEAU | 44×44px — `width: 44px; height: 44px` |
| Liens nav panneau hamburger | NOUVEAU | 48px de hauteur (`height: 48px` — dépasse le minimum) |
| Liens nav desktop (masqués mobile) | 11px texte — touch target insuffisant | Masqués sur mobile via `@media` — non impacté |
| Filtres galerie (pills) | À vérifier | Minimum 44px de hauteur via `padding` |
| Bouton "Faire une offre" | À vérifier | Minimum 44×44px |
| Badges statut cliquables | À vérifier | Minimum 44×44px |
| Carré initiale nav | 28×28px | Non interactif seul — wrappé dans un `<Link>` avec padding |
