## A) FilterBar.tsx — scroll horizontal mobile

Le conteneur actuel utilise `flexWrap: 'wrap'` — les chips passent à la ligne sur mobile.
Sur mobile, ils doivent défiler horizontalement sur une seule ligne.

Modifier le div container de FilterBar.tsx :

1. Remplacer le style inline `flexWrap: 'wrap'` par une classe CSS :
   Changer :
   ```tsx
   <div style={{ display: 'flex', flexWrap: 'wrap', gap: 6, alignItems: 'center' }}>
   ```
   En :
   ```tsx
   <>
     {/*
      * Scroll horizontal sur mobile : les chips ne passent plus à la ligne.
      * POURQUOI className et <style> plutôt que style inline ?
      * flexWrap et overflow-x ne peuvent pas avoir deux valeurs différentes
      * pour desktop et mobile en style inline — @media est obligatoire.
      * [08-RESEARCH.md Pattern 2 — masquage conditionnel via <style> inline]
      */}
     <style>{`
       .filterbar-container {
         display: flex;
         flex-wrap: wrap;
         gap: 6px;
         align-items: center;
       }
       @media (max-width: 768px) {
         .filterbar-container {
           flex-wrap: nowrap;
           overflow-x: auto;
           /* Masquer la scrollbar horizontale — cosmétique uniquement */
           -webkit-overflow-scrolling: touch;
           scrollbar-width: none;
         }
         .filterbar-container::-webkit-scrollbar {
           display: none;
         }
       }
     `}</style>
     <div className="filterbar-container">
       {/* chips inchangés */}
     </div>
   </>
   ```

IMPORTANT : Conserver TOUS les chips inchangés (la logique isActive, isEmpty, counts reste identique).
Conserver le commentaire d'en-tête existant du fichier.

## B) artworks/[id]/page.tsx — panel info non-sticky sur mobile

Le panel info a `position: sticky; top: 0; maxHeight: 100vh` en style inline.
En mode 1-colonne (≤1023px), la deuxième colonne est empilée sous la première —
la règle sticky confine le contenu dans 100vh et peut empêcher de scroller jusqu'au formulaire.

Modifier `artworks/[id]/page.tsx` :

1. Ajouter la classe `detail-info-panel` et `detail-info-scroll` au div du panel et au scroll container :
   Modifier le div panel (actuel : lignes 375-383) :
   ```tsx
   {/* ── Colonne droite : panel info (D-14) ─────────────────────────── */}
   <div
     className="detail-info-panel"
     style={{
       backgroundColor: 'var(--color-surface)',
       padding: '32px 32px 28px',
       overflowY: 'auto',
       maxHeight: '100vh',
       position: 'sticky',
       top: 0,
     }}
   >
   ```

2. Étendre la balise `<style>` EXISTANTE dans la page (lignes 267-278) :
   Changer :
   ```tsx
   <style>{`
     .detail-grid {
       display: grid;
       grid-template-columns: 1fr 420px;
       min-height: calc(100vh - 56px);
     }
     @media (max-width: 1023px) {
       .detail-grid {
         grid-template-columns: 1fr;
       }
     }
   `}</style>
   ```
   En :
   ```tsx
   <style>{`
     .detail-grid {
       display: grid;
       grid-template-columns: 1fr 420px;
       min-height: calc(100vh - 56px);
     }
     @media (max-width: 1023px) {
       .detail-grid {
         grid-template-columns: 1fr;
       }
     }

     /*
      * Panel info : non-sticky sur mobile (≤1023px).
      * POURQUOI désactiver sticky sur mobile ?
      * En layout 1-colonne, le panel est empilé sous l'image — sticky + maxHeight: 100vh
      * confine le contenu dans 100vh et peut masquer le formulaire d'offre.
      * Sur desktop (≥1024px), sticky + maxHeight: 100vh reste actif (comportement voulu).
      * [08-RESEARCH.md Pitfall 7 — panel sticky bloque scroll vers OfferForm]
      *
      * scroll-padding-bottom : réserve 80px en bas du scroll container.
      * Quand le clavier virtuel s'ouvre, le navigateur scroll pour révéler
      * le champ focused — le padding évite que le champ soit coupé par le clavier.
      */
     @media (max-width: 1023px) {
       .detail-info-panel {
         position: static;
         max-height: none;
         overflow-y: visible;
         scroll-padding-bottom: 80px;
       }
     }
   `}</style>
   ```

3. Ajouter `className="detail-info-panel"` sur le div panel (sans supprimer le style inline) :
   ```tsx
   <div
     className="detail-info-panel"
     style={{
       backgroundColor: 'var(--color-surface)',
       padding: '32px 32px 28px',
       overflowY: 'auto',
       maxHeight: '100vh',
       position: 'sticky',
       top: 0,
     }}
   >
   ```
   Note : Les valeurs sticky/maxHeight dans le style inline sont overridées par les règles @media
   sur mobile. Sur desktop (≥1024px), le style inline s'applique (pas de règle @media pour overrider).
